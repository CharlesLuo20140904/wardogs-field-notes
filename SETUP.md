# Publishing checklist

1. Review every article's official source card after a game update, then update its review date if the claim still holds.
2. Add the public Google Analytics measurement ID and final `https://your-domain.example` address in `assets/scripts/site-config.js` if you want analytics.
3. Add the final domain to GitHub Pages, then create a `sitemap.xml` using that exact canonical domain.
4. Keep unverified build numbers, drop rates, map spawns and permanent rankings out of published articles until they have a current source and a dated verification.

## Analytics

The site sends no analytics requests by default. Adding a measurement ID activates page and click reporting through Google Analytics. Review your privacy and cookie obligations for the countries you serve before enabling it.
